
# AI Applications Showcase

A showcase of AI-powered web applications, custom WordPress development, intelligent assistants and generative AI integrations.

## 1. Nastroje-AI.sk – AI Tools & Information Portal

Nastroje-AI.sk is an independent Slovak-language WordPress portal dedicated to artificial intelligence, AI tools, practical tutorials and emerging AI technologies.

The platform combines educational content with freely accessible AI-powered tools and application demonstrations.

**[Visit Website](https://nastroje-ai.sk/)**

## 2. Custom WordPress AI Assistant

A custom AI-powered WordPress plugin developed for Nastroje-AI.sk.

The assistant combines conversational AI with website content and business information to provide relevant responses to visitors.

### Key Features

- Interactive AI chat interface
- Website content integration
- Custom WordPress administration dashboard
- Conversation management
- Lead capture
- Usage analytics
- API authentication
- Rate limiting
- Supabase integration

**[Explore the AI Assistant on Nastroje-AI.sk](https://nastroje-ai.sk/)**

## 3. AI Live TV

An experimental generative AI web application focused on AI-powered video generation.

The project explores the integration of modern generative AI models with web interfaces and cloud-based processing.

### Development Focus

- AI video generation
- Generative AI model integration
- Hugging Face infrastructure
- Backend API communication
- Generation queue management
- Cloud deployment

**[Visit AI Live TV](https://ai-live-tv.netlify.app/)**
